# The --fast profile of tools/local_validate.py: which tests it runs, and what each one covers.
# Entries are relative to the directory they are run from: [pytest] from bindings/python, [pylance] from
# pylance's tests/ (tools/pylance_suite.py --files). "file::test" runs one test with all its parameters.
# The seconds after each entry are its share of the full run's serial time (4 cores; measured with other work
# on the machine, so a quieter one is faster). The whole [pytest] list took about 210 s in the measured run.
