    4. Implementation¶

    • C++: the manifest index entry (write and read: wherever nanolance reads and rewrites index entries, a __lance_mem_wal entry is carried over untouched, as Lance carries it), the commit (the transaction pylance writes, measured in 3.1), the sharding hash (in C++ if the Python layer reaches it through _nanolance, else Python is fine for M1 -- say which and why).
    • Python: LanceDataset.initialize_mem_wal, mem_wal_index_details, module nanolance/lance/mem_wal.py mirroring pylance's names (ShardingField, ShardingSpec, evaluate_sharding_spec, and the M2 classes as refusals), the error messages the targets match.
    • Interop: pylance opens a dataset nanolance initialized and returns the same mem_wal_index_details(); nanolance opens one pylance initialized and returns pylance's dict.

    5. Tests you write¶

    bindings/python/tests/test_mem_wal.py (require_pylance()): every initialize form through both engines, details equal; each engine reads the other's; the 3.2 operations on a pylance-initialized dataset keep the entry (manifest-compared with pylance doing the same); evaluate_sharding_spec over the 3.3 inputs equal to pylance's.

    6. Rules¶

    AGENTS.md sections 5 and 7. No skipped or weakened tests; no except Exception around failures. The local native build has -DNANOLANCE_WERROR=ON: delete helpers you stop using. Do not add fields to Python classes that mirror pylance's. Do not commit, push, change branches, or run --update. A dataset without MemWAL must be written exactly as before (same manifest bytes for every operation). Builds: cd build && ninja, then cd bindings/python && python3 -m pip install -q -e . (use python3 -m pip: bare pip here is another Python). Run each full suite once, at the end; the bindings suite with | grep -E "^(FAILED|ERROR)|passed|failed" | tail -15.

    7. Stop and ask (question first in the report)¶

    • the __lance_mem_wal entry needs a manifest field or feature flag nanolance does not have;
    • an operation of 3.2 cannot keep the entry without touching code M2 would own;
    • a pylance test that passes today fails.
